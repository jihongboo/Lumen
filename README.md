# Lumen Noise

Lumen Noise is an ambient clock and natural soundscape application designed specifically for the Apple ecosystem. It transforms your iPhone, iPad, Mac, or Apple TV screen into a tranquil digital window, blending time display, real-time weather, gentle motion visuals, and high-quality natural background sounds.

## Key Features

- **Minimalist Ambient Clock**: Full-screen time interface perfect for desks, bedside tables, or as a room background.
- **Dynamic Weather Visuals**: The interface automatically adjusts its visual atmosphere based on your local real-time weather, keeping your screen in sync with the world outside.
- **High-Quality Soundscapes**: Built-in sounds like rain, ocean waves, forest, wind, and campfire to help you focus, relax, or fall asleep.
- **Universal Apple Support**: Optimized for iOS, iPadOS, macOS, and tvOS, adapting perfectly to all screen sizes from mobile devices to large TVs.

## Project Structure

- `Lumen/`: Core source code (Swift/SwiftUI).
- `docs/`: Official website and support documentation.
  - `index.html`: Product landing page.
  - `support.html`: FAQ and technical support.
  - `privacy.html`: Privacy policy.
- `Screenshot/`: Beautiful app screenshots for all platforms.
- `Tools/`: Helper scripts and tools for development.

## Preview the Website

If you want to preview the Lumen Noise marketing website locally:

1. Open a terminal and navigate to the project root directory.
2. Start a local server (requires Python 3):
   ```bash
   python3 -m http.server 8000 --directory docs
   ```
3. Visit `http://localhost:8000` in your browser.

## Privacy Commitment

Lumen Noise prioritizes user privacy. The app only requests location access when necessary to provide weather services. All data is processed locally on your device, and no personally identifiable information is stored or uploaded.
